What does success actually cost?

Change the price, first-attempt success probability, and effectiveness of retry feedback. Compare the expected bill per verified completion, not the sticker price of a model call.

What is being calculated?

Each new attempt is paid for only if all earlier attempts failed. The model combines expected spending across all task starts with the probability of completing a task within the attempt limit. Dividing those quantities yields expected expenditure per verified success across a large batch of comparable tasks.

Important assumption

Success probabilities are your estimates. Subsequent attempts gain a fixed percentage-point improvement from feedback, with probabilities capped at 100%. The price per attempt is constant inside a configuration. No model performance is measured here. If each retry has identical independent success probability and price, changing the attempt limit changes completion probability but leaves the expected cost per success unchanged.

Cost / success = E[spend per task] / P(success)
