Start with your existing work.

Python 3.11+. Offline inspection needs no provider credentials or Docker.

Install and exploreSynthetic demo
git clone https://github.com/fraware/cost-to-done.git
cd cost-to-done
python -m venv .venv
source .venv/bin/activate
python -m pip install -e .
cost-to-done demo --output demo.html

Open demo.html in your browser. On Windows use .venv\Scripts\activate. Choose a fresh output filename.

How the accounting works

Compare complete trials against a fixed task and retry policy.

Cost per verified completion

Total expenditure across all completed trialsVerified successful trials

Zero successes: undefined. Failed attempts and failed trials count toward expenditure.

Match the task and acceptance criteria
Pin task identity, verifier, replication and execution settings.
Account for failed work
Retain all measured attempts. Separate estimated prices from billed charges.
Expose unresolved observations
Never impute missing cost as zero. Planned comparisons withhold ratios when support is incomplete.

Bring your own repository task

Package selected committed Python source and acceptance tests for Harbor.

Prepare a taskNo inference
cost-to-done prepare-repo-task \
  --repository ./my-repo --name repair-addition \
  --source app/calc.py --test acceptance/test_calc.py \
  --instruction repair.md --output ./repair-task

cost-to-done validate-repo-task ./repair-task

Current execution scope

Committed-file packaging, starter/reference qualification and matched external-task gateway rehearsal are implemented.
