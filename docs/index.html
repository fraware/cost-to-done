Cost to Done makes the trial the unit of accounting. The verifier defines success, and all charged work contributes to the denominator-adjusted cost.

01 / PIN

Same task. Same tests.

Keep input tasks, scoring definitions, trial counts, and execution settings pinned for each comparison.

02 / OBSERVE

Failures cost money.

Retain attempts, tokens, retries, tool use, elapsed time, infrastructure incidents, and reported charges.

03 / VERIFY

Earn the pass.

Grade real artifacts against a verifier the agent did not control. Attach complete receipts and uncertainty, with the trust boundary stated.

Usable today

Two Harbor runs.
One local comparison.

Bring two completed Harbor jobs. Compare task outcomes, elapsed time and available agent-reported costs side by side. No credentials or new inference requests.

# Python 3.11+ · offline inspection
python -m pip install -e .

# Compare existing Harbor jobs
cost-to-done compare-harbor \
  fast=/path/to/harbor-job-a \
  careful=/path/to/harbor-job-b \
  --output comparison.html

# Or inspect one job
cost-to-done report-harbor /path/to/job \
  --output evidence.html
